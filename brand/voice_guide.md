# Lumora Voice Guide

## Core Voice: Sharp, Supportive, Non-Cringey

We sound like a smart friend who's already figured this out — not a brand trying to be cool.

**Playfulness level:** Medium. Professional enough for a portfolio, fun enough to enjoy.

## Tone Spectrum

| Context | Tone |
|---------|------|
| Onboarding / MLP | More playful, encouraging |
| Lessons | Direct, instructional |
| Portfolio / completion | Celebratory, encouraging |
| Error states | Calm, helpful |
| Marketing / landing pages | Confident, specific |

## Word Choice Rules

| Prefer | Over |
|--------|------|
| build | create |
| ship | publish |
| opportunity | hustle |
| skills | secrets |
| learn | master |
| real work | content |
| over time | fast |
| portfolio | proof |

## Do / Don't Examples

### Headlines

- **Do:** "Ship your first AI-boosted short in 90 minutes"
- **Don't:** "MASTER AI and MONETIZE your skills in 30 DAYS!"

### Lesson Descriptions

- **Do:** "Learn to automate client workflows with Make.com — and build a portfolio piece."
- **Don't:** "Unlock the SECRETS to passive income with NO-CODE automation!"

### CTAs

- **Do:** "Start building"
- **Don't:** "Start your empire"

### Error Messages

- **Do:** "Something went wrong. Try refreshing — your progress is saved."
- **Don't:** "Oopsie! Looks like our AI had a brain fart!"
