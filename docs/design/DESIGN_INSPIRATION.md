### Pattern 6: Vapor/Prism Color Shifts
**Source:** formless.xyz (PRIMARY INTERACTIVE PATTERN)
**Usage:** Section backgrounds, hover states, scroll transitions
**Implementation:**
```css
/* Layer multiple radial gradients */
background:
  radial-gradient(circle at 30% 50%, #1a0a2e 0%, transparent 70%),
  radial-gradient(circle at 70% 50%, rgba(0,212,255,0.2) 0%, transparent 50%),
  radial-gradient(circle at 50% 80%, rgba(255,0,110,0.15) 0%, transparent 60%),
  #1a1a2e;
mix-blend-mode: overlay;
transition: all 1.5s ease-in-out;
```
**Scroll Behavior (Framer Motion):**
```typescript
const { scrollYProgress } = useScroll();
const gradientX = useTransform(scrollYProgress, [0, 1], ['30%', '70%']);
const gradientY = useTransform(scrollYProgress, [0, 1], ['50%', '80%']);
```
**Mouse Parallax:**
- Track mouse position
- Offset gradient centers by mouse coords / 50
- Creates prism refraction effect on hover
**Color Progression:**
- Section 1: Purple/Navy base
- Scroll 25%: Cyan appears
- Scroll 50%: Magenta appears
- Scroll 75%: Purple intensifies
- Scroll 100%: Gold highlights
**Quality Gates:**
- Smooth 1-2s transitions (never jarring)
- Subtle, elegant (not overwhelming)
- 60fps animations (use transform, opacity only)
- Works on mobile (simplified, fewer gradients)

## 🎯 INTERACTION PATTERNS CATALOG

### Hover Glow Effects
**Sources:** Blackbox, Pytia, formless.xyz
**Element:** Cards, buttons, links
**Default State:** Subtle border (rgba(255,255,255,0.08))
**Hover State:**
- Border: Cyan or magenta (rgba(0,212,255,0.3))
- Shadow: 0 0 20px rgba(0,212,255,0.3)
- Transition: 300ms ease-in-out
- Transform: translateY(-2px) for lift
**Implementation:**
```css
.glass-card {
  border: 1px solid rgba(255,255,255,0.08);
  transition: all 300ms ease-in-out;
}
.glass-card:hover {
  border: 1px solid rgba(0,212,255,0.3);
  box-shadow: 0 0 20px rgba(0,212,255,0.3), 0 8px 32px rgba(0,0,0,0.3);
  transform: translateY(-2px);
}
```
